# 126p — Studium małego samochodu

Interaktywna ekspozycja 3D **Polskiego Fiata 126p 600 z 1976 roku** (pierwsza seria) w przeglądarce.

**Na żywo:** https://apkmason.dev/maluch/

Można obejrzeć nadwozie, kabinę, bagażnik, silnik i podwozie, otworzyć drzwi, bagażnik, pokrywę silnika i uchylne szybki, włączyć światła, kierunkowskazy i wycieraczki, skręcić koła kierownicą, zmienić lakier (czerwony lub biały, najczęstsze w Polsce) i przejrzeć galerię ilustracji. Opcjonalnie można włączyć muzykę.

## Sterowanie

| Akcja | Mysz / klawiatura |
|---|---|
| Obrót | lewy przycisk + przeciągnięcie |
| Przybliżenie | kółko |
| Przesunięcie | prawy przycisk + przeciągnięcie |
| Widoki: nadwozie, wnętrze, silnik, podwozie | zakładki lub **1–4** |
| Reset kamery | **R** |
| Drzwi / uchylne szybki | **D** / **V** |
| Światła / kierunkowskazy (lewy → prawy → awaryjne) | **L** / **K** |
| Wycieraczki / skręt kół | **W** / **S** |
| Muzyka (domyślnie wyłączona) | **M** |
| Zamknięcie okna | **Esc** |

W widoku wnętrza przycisk **Usiądź za kierownicą** przełącza na widok z fotela kierowcy.

## O modelu

Główne wymiary (3054 × 1377 × 1335 mm, rozstaw osi 1840 mm, rozstaw kół 1142 / 1203 mm) i przekroje nadwozia odczytano z fabrycznego arkusza wymiarowego Fiata (XI 1973). Zgodność sprawdzono, nakładając go na rzuty modelu. Detale odtworzono ze zdjęć fabrycznych i egzemplarzy z lat 1973–1976.

To edukacyjna rekonstrukcja, a nie skan ani dokumentacja naprawcza. Silnik i podwozie pokazują układ zespołów w uproszczeniu.

**Galeria** zawiera ilustracje wygenerowane z pomocą AI. Nie są to fotografie archiwalne, a ich detale mogą odbiegać od oryginału. **Muzyka** powstała na potrzeby projektu w Suno (plan płatny).

## Źródła

- Fiat, *126 Uso e manutenzione*, 1976 — wymiary, koła, wyposażenie
- Fiat, dokumentacja serwisowa *Modell 126 — Allgemeines*, XI 1973 — rzuty i fotografie pierwszej serii
- Fiat / Stellantis, „Fiat 126p Maluch — 40 lat minęło” — historia produkcji
- Rezerwa 126p — kolory pierwszej serii

Pełne odnośniki są w oknie **Dokumentacja** na stronie.

## Technologia

Model przygotowano w Blenderze i skompresowano (glTF + Meshopt). Stronę renderuje Three.js, a zbudowano ją w Vite. Nie ma tu kont, analityki ani zewnętrznych usług. Scena jest rysowana tylko wtedy, gdy coś się porusza.

To repozytorium zawiera wyłącznie zbudowaną stronę publikowaną przez GitHub Pages.
